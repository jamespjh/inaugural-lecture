```bash
quarto check

```

## Asset Structure

Assets are organized into three categories:

### Sources
- `assets/sources/teachgrav/scenarios.yml` - Source configuration for teaching scenarios
- `assets/sources/graphviz/` - Source Graphviz DOT files  
- `assets/sources/prompts/` - Source prompt files

### Generated
- Automatically generated files (SVGs, videos, etc.) placed in `assets/generated/`

### Stored
- Permanently stored static files (images, etc.) placed in `assets/stored/`

## Asset Generation

Slide assets (videos, images) are auto-generated by GitHub Actions CI.
To generate assets locally:

```bash
cd slideshow/assets
source ../../demo/venv/bin/activate
generate-figures scenarios.yml
```

Before this works, ensure teachgrav is installed via `pip install -e ../../demo/`.

## UCL Logo Conversion

Run from repo root to regenerate `assets/ucl-logo.png` from `assets/ucl-logo-original.png`:

```bash
set -e
cd /Users/jamespjh/devel/inaugural/slideshow/assets
source /Users/jamespjh/devel/inaugural/demo/venv/bin/activate
python ucl-logo-conversion.py --input ucl-logo-original.png --output ucl-logo.png
```
