# Plan: Solar-System Scenario

## Issue

Implement a new `solar_system` scenario in the `teachgrav` demo package.

## Requirements (from issue)

- New scenario `solar_system` with planets orbiting a sun, each with optional moons.
- No bodies are immobile.
- Moon mass = 1, planet mass = M, sun mass = M^2 (M > 1).
- Planet radii spaced by ratio k: 1, k, k^2, k^3, …
- Moon radii relative to their planet: innermost at h, second hk, etc. (h * k^j).
- Initial speeds derived from circular-orbit mechanics: v = sqrt(M_central / r).
- Constructor parameter `moons_per_planet`: array whose length = number of planets,
  elements = number of moons for each planet. Default `[0, 1, 4, 1]`.
- Constructor parameters M (default 1000), k (default 1.2), h (default 0.1).

## Steps

1. Create `demo/src/teachgrav/scenarios/solar_system.py` with `SolarSystemScenario`.
   - Follows the naming convention: "solar_system" → `SolarSystemScenario`.
   - `create(moons_per_planet, M, k, h)` builds the body list and returns a `System`.
   - Sun at origin, planets along positive x-axis at radii k^i, moons offset further
     along x-axis at h*k^j from their planet.
   - Orbital velocities (perpendicular, y-direction) from v = sqrt(M_central / r).

2. Update `KNOWN_SCENARIOS` in `demo/src/teachgrav/scenarios/__init__.py`
   to include `'solar_system'`.

3. Add tests in `demo/tests/teachgrav/test_scenarios.py`:
   - Default body count (11 bodies for default [0,1,4,1]).
   - Custom moons_per_planet body count.
   - No moons case.
   - Mass values (sun=M^2, planet=M, moon=1).
   - Planet radii placement.
   - Orbital velocity values for planets.
   - Moon velocity values (planet velocity + orbital component).
