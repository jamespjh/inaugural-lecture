# Plan: Implement the Boids Law

Implement Craig Reynolds' Boids flocking algorithm as a law in the teachgrav
simulation framework (issue: "Implement the Boids law").

## Steps

1. Create `demo/src/teachgrav/laws/boids_law.py` implementing `BoidsLawModel`.
   - Three rules: cohesion (fly toward centre of flock), separation (avoid
     nearby boids), alignment (match velocity with nearby boids).
   - Follows the same `flat_law` / `Model` interface as `constant_law.py`
     and `pl.py`.
   - Parameters: `flock_attraction`, `avoidance_radius`,
     `formation_flying_radius`, `speed_matching_strength` (defaults matching
     original bad-boids/better_boids implementation).

2. Add `boids` scenario to `demo/src/teachgrav/scenarios.py`.
   - `init_boids(n_boids=50)` initialises positions and velocities matching
     the original bad-boids random initialisation (x ∈ [−450, 50],
     y ∈ [300, 600], xv ∈ [0, 10], yv ∈ [−20, 20]).
   - Equal masses for all boids (1.0 each).

3. Register `boids` in `demo/src/teachgrav/laws/laws.py` `create_law()`.

4. Update `demo/src/teachgrav/entry.py`:
   - Add `boids` to `--law` choices.
   - Add `boids` to `--scenario` choices.
   - Add `--dt` and `--until` CLI arguments (with defaults 0.01 and 10.0)
     so the boids scenario can use `--dt 1 --until 600` to match the
     original discrete-time semantics.
   - Thread `args.dt` and `args.until` through to `solve()`.

5. Write `demo/tests/teachgrav/test_boids_law.py` with 10 targeted tests:
   - Output shape, derivative semantics, immobile mask.
   - Behavioural tests for each of the three rules in isolation.
   - Parameterised test for a range of flock sizes.

6. Add boids entry to `slideshow/assets/scenarios.yml` (dt=1, until=600,
   duration=30, outfile=boids_euler.mp4).

7. Update `slideshow/part1.qmd` slide 1.1.7:
   - Replace `[Demo should show the Boids]` placeholder with boids video.
   - Replace `[Fill in here]` with the three boids rules.
   - Embed the generated `assets/boids_euler.mp4` as an HTML5 `<video>` tag
     inside a Pandoc raw block.

## Decisions

- Used the original bad-boids position/velocity scale and parameter defaults
  so that running with `--dt 1` produces behaviour equivalent to the original
  discrete Boids simulation.
- Added `--dt` / `--until` to the CLI as they are generally useful and needed
  to configure the boids video generation.
- Did not add `--n-boids` CLI arg; the default of 50 is sufficient for the
  demo video.
- Boids law works with the existing Euler integrator and does not require JAX.
