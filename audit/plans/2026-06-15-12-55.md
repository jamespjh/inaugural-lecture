# Plan: NxN Grid Visualisation for Stochastic Scenario Samples

## Objective
Add a `--grid N` CLI flag (and corresponding YAML key `grid: N`) that generates an
NxN static image where each cell shows the trail visualisation of one independent
sample from a stochastic scenario.  Invoke it for a 5×5 grid of the `scatter`
scenario with 4 bodies as the canonical example.

## Requirements
1. New `grid_plot` function in `visualisations/visualize.py`
2. `--grid N` flag in `entry.py` (`parse_args`, `_validate_args`, `execute_scenario`)
3. `generate.py` already converts YAML integer keys to CLI args via
   `_config_to_force_args` – no changes needed there
4. Focused tests (mocking heavy simulation where appropriate)
5. A fixture YAML for the 5×5 scatter example
6. Audit plan and prompt files

## Files to Modify / Create
- `demo/src/teachgrav/visualisations/visualize.py`  – add `grid_plot`
- `demo/src/teachgrav/entry.py`                    – add `--grid`, validation,
                                                      `_execute_grid_scenario`
- `demo/tests/teachgrav/test_viz.py`               – tests for `grid_plot`
- `demo/tests/teachgrav/test_entry.py`             – tests for `--grid` CLI

## Key Design Decisions
- `grid_plot` renders each trajectory using the existing trail style (lines per
  body) in a compact NxN subplot grid.
- Each cell is auto-scaled independently using `_equal_aspect_limits`.
- `--grid N` intercepts the normal visualise/write flow in `execute_scenario` and
  returns early after saving the grid image.
- When no `--outfile` is provided in grid mode, the plot is shown interactively
  (consistent with other visualisation paths).
- Validation: grid must be ≥ 1; no outfile needed for interactive show.
