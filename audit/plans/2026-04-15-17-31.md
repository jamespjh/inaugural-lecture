# Plan: Add --benchmark-solve CLI flag for ODE solver benchmarking

## Issue

The issue asks to add a `--benchmark-solve` flag that benchmarks the full ODE solver
(as opposed to `--benchmark` which benchmarks a single law evaluation). The ODE solver
benchmark should use `--until` from the parameters. Both flags must not be used together.

## Requirements (from issue comments by @jamespjh)

- Leave `--benchmark` to benchmark the law only (unchanged).
- Add `--benchmark-solve` to benchmark a small amount of ODE evolution.
- `--benchmark-solve` picks up `--until` from the parameters.
- Error if both `--benchmark` and `--benchmark-solve` are given.

## Changes

### `demo/src/teachgrav/entry.py`

1. Add `--benchmark-solve` argument to `parse_args()` with `dest='benchmark_solve'`
   and `action='store_true'`.
2. Add mutual exclusion check in `_validate_args()`: raise `ValueError` if both
   `args.benchmark` and `args.benchmark_solve` are set.
3. Add `benchmark_solve_scenario(args)` function that:
   - Creates a `ScenarioFactory` and scenario system.
   - Wraps a `solve(...)` call in a closure.
   - Times it via `benchmark_engine(run_once, args.engine)`.
   - Returns the mean timing in seconds.
4. Update `execute_scenario()` to check `args.benchmark_solve` after the existing
   `args.benchmark` check, calling `benchmark_solve_scenario(args)` and returning.

### `demo/tests/teachgrav/test_entry.py`

1. Add `benchmark_solve = False` to both existing `Args` mock classes (in
   `test_benchmark_mode_passes_law_and_timing` and
   `test_benchmark_mode_runs_single_law_step_not_full_solve`) to prevent
   `AttributeError` from the new `args.benchmark_solve` access in `execute_scenario`.
2. Add `test_benchmark_solve_parse_args`: verifies `--benchmark-solve` sets
   `args.benchmark_solve = True` and leaves `args.benchmark = False`.
3. Add `test_benchmark_and_benchmark_solve_together_raises`: verifies a `ValueError`
   is raised when both flags are supplied.
4. Add `test_benchmark_solve_calls_solve_not_law`: verifies `solve()` is called once
   and the law is not called directly in `--benchmark-solve` mode.
5. Add `test_benchmark_solve_respects_until`: verifies `--until` is passed through
   to `solve()`.
