     name → `<Name>Scenario` class via metaprogramming
   - `ScenarioFactory` class whose `create_scenario(name, **kwargs)` calls
     `_load_scenario_class` then instantiates and calls `.create(**kwargs)`
   - `create_training_data()` method preserved unchanged

5. Delete old `scenarios.py` (the new package directory takes precedence, but

6. Verify existing tests all pass; run flake8; add plan and prompts files.

## Metaprogramming convention

```
name "foo"
  → module teachgrav.scenarios.foo
  → class  FooScenario
```

Adding a new scenario only requires a new module following this convention
and adding its name to `KNOWN_SCENARIOS` for help-text purposes.

## Backward compatibility

`from teachgrav.scenarios import ScenarioFactory, STOCHASTIC_SCENARIOS` still
works unchanged because `scenarios/__init__.py` exports both symbols.
