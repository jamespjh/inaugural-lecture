# Plan: Add --moons-per-planet CLI switch

**Date:** 2026-06-15

## Goal

Add a CLI argument `--moons-per-planet` so users can pass a moon-count array
to the `solar_system` scenario from the command line.

## Steps

1. Add `--moons-per-planet` argument to `parse_args()` in `entry.py`
   - `nargs='+'`, `type=int`, `dest='moons_per_planet'`, `default=None`
2. In `execute_scenario()`, when `args.moons_per_planet is not None`, add it to
   `scenario_kwargs`.
3. In `_validate_args()`, guard that `--moons-per-planet` is only used with
   `--scenario solar_system`, raising a clear `ValueError` otherwise.
4. Add `moons_per_planet = None` to all mock `Args` classes in `test_entry.py`
   to avoid `AttributeError` in existing tests.
5. Add three new tests to `test_entry.py`:
   - `test_moons_per_planet_solar_system` — parses correctly
   - `test_moons_per_planet_default_is_none` — default is None
   - `test_moons_per_planet_non_solar_system_raises` — wrong scenario raises
