# Plan: Make the number of bodies for scatter scenario specifiable as CLI parameter

## Issue
Add a `--n-bodies` command-line parameter to the `teachgrav` CLI that controls the number of bodies in the `scatter` scenario. The parameter should be rejected (with an error) when used with any other scenario.

## Changes

### `demo/src/teachgrav/entry.py`
1. Add `--n-bodies` argument in `parse_args()` (integer, optional, default `None`)
2. After parsing, validate: if `args.n_bodies is not None` and `args.scenario != 'scatter'`, raise `ValueError` with a descriptive message
3. In `execute_scenario`, pass `n_bodies=args.n_bodies` to `create_scenario` when `args.n_bodies` is not None (or always pass it as kwargs)

### `demo/tests/teachgrav/test_entry.py`
1. Test that `--n-bodies 6 --scenario scatter` results in `args.n_bodies == 6`
2. Test that `--n-bodies` defaults to `None`
3. Test that using `--n-bodies` with `moon` scenario raises `ValueError`
4. Test that using `--n-bodies` with `sun` scenario raises `ValueError`
5. Test that using `--n-bodies` with `single` scenario raises `ValueError`

## Acceptance Criteria
- `--n-bodies N` works with `--scenario scatter` and creates N bodies
- `--n-bodies N` with any non-scatter scenario raises an error
- Existing tests continue to pass
