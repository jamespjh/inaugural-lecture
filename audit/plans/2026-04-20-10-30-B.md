# Plan: figsize/aspect support for visualisation entry points

## Goal
Add figure size awareness to all visualisation entry points so that the width of the data viewport is proportional to the screen width in inches, and expose a simple `--aspect` CLI flag (`page` or `column`) to control the preset size.

## Steps

1. **`_equal_aspect_limits` in `visualize.py`** — accept `figsize=(w, h)` and scale x axis by `w/h` so one data unit spans the same pixels in both directions. Handle the case where x data extent is larger than y.

2. **`_ASPECT_FIGSIZE` and `figsize_from_aspect()`** — define once in `visualize.py`; import everywhere else.

3. **Entry points** — add `figsize` kwarg (default `(6.4, 7.2)` = column preset) to `axes`, `animate`, `plot`, `visualize`, `convergence_video`, `generate_convergence_video`.

4. **`entry.py`** — add `--aspect` argparse argument (`page`|`column`, default `column`); resolve to `figsize` tuple in `_validate_args` and forward to `visualize` and `_generate_convergence_video`.

5. **`generate.py`** — read `aspect` from each YAML config entry in `_run_multi_scenario_benchmark` and `_run_single_scenario_benchmark`; lift figure/CSV routing out of `_write_benchmark_csv` so it becomes a pure CSV writer.

6. **Tests** — update `test_viz.py`, `test_generate.py`, `test_convergence_video.py`.

## Defaults
- `column`: 6.4 × 7.2 in (half of a 16:9 slide width, full height)
- `page`: 12.8 × 7.2 in (full 16:9 slide)
