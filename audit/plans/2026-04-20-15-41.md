# Plan: CuPy Compatibility for Array Namespace and Host Conversion

## Objective
Fix CuPy test failures in two families by adding array namespace compatibility and explicit host conversion support.

## Requirements
1. Reproduce CuPy failures in the demo test suite
2. Fix AttributeError for missing `__array_namespace__` on CuPy arrays
3. Fix TypeError for implicit NumPy conversion on CuPy arrays
4. Keep changes minimal and backend-focused
5. Validate with CuPy-targeted tests

## Implementation Steps
1. Add a one-time CuPy monkeypatch in the CuPy engine setup to provide `cupy.ndarray.__array_namespace__`
2. Update `to_numpy_host` to use explicit `.get()` transfer when available before `np.asarray`
3. Run focused CuPy reproducer tests for array abstraction and GP
4. Run broader CuPy coverage (`test_boids_law.py` and `pytest -k cupy`) to confirm no regressions

- demo/src/teachgrav/engines/cupy_engine.py
- demo/src/teachgrav/engines/base.py
