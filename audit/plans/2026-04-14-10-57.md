# Plan: Benchmark figure via CI/CD (Issue #46 – revised)

## Date: 2026-04-14 (revision)

## Context

The initial implementation generated the figure in a Jupyter notebook and committed
the PNG. The correct approach (per PR review feedback) is:

- Use the existing `generate-figures --benchmark` CLI entry point with a YAML
  sweep config.
- Add a `plot-benchmark` CLI entry point to convert the CSV output to a PNG.
- Wire both steps into the slides CI/CD pipeline so the figure is generated
  automatically on every push rather than committed to the repo.

## Changes

### `slideshow/assets/benchmark_engines.yml` (new)
YAML sweep config for the `generate-figures --benchmark` entry point.  Each
top-level entry is one engine; the `n-bodies` list is the row sweep axis.
Produces a CSV with columns `n-bodies, numpy, jax-cpu`.

### `demo/src/teachgrav/plot_benchmark.py` (new)
CLI script (`plot-benchmark`) that reads the benchmark CSV and writes a
log–log PNG.  One line per engine column; NaN/blank values are skipped
gracefully.  Colours are pulled from `ENGINE_COLORS` dict keyed by engine name.

### `demo/pyproject.toml`
Register `plot-benchmark = "teachgrav.plot_benchmark:main"` as a console script.

### `.github/workflows/slides.yml`
- Install `'.[jax]'` extras so `jax-cpu` is available.
- Add "Generate benchmark figure" step that runs:
  1. `generate-figures --benchmark benchmark_engines.yml --output benchmark_engines.csv`
  2. `plot-benchmark benchmark_engines.csv benchmark_engines.png`

### `.gitignore`
Add `slideshow/assets/benchmark_engines.csv` and
`slideshow/assets/benchmark_engines.png` so generated files are never committed.
