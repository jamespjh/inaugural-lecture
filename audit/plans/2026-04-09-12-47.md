## Plan: Make RNG Seed Passable as Parameter

Allow users to pass a random seed so that stochastic scenarios (e.g. `scatter`) are reproducible. Different engines handle seeds differently, so each must be handled explicitly.

**Steps**

1. Update `ArrayAbstraction.__init__` to accept an optional `seed` parameter.
   - numpy: use `np.random.default_rng(seed)` stored as `self.rng`, replacing global `np.random.uniform` calls.
   - JAX: use `jrandom.key(seed if seed is not None else 0)` instead of hardcoded `jrandom.key(0)`.
   - MLX: call `mx.random.seed(seed)` when seed is provided.
2. Update `random_array` in `ArrayAbstraction` to use `self.rng.uniform` for the numpy engine.
3. Update `ScenarioFactory.__init__` to accept `seed=None` and forward it to `ArrayAbstraction`.
4. Update `entry.py` `parse_args` to add a `--seed` CLI argument (int, default None).
5. Update `execute_scenario` in `entry.py` to pass `args.seed` to `ScenarioFactory`.
6. Add tests in `test_scenarios.py`:
   - Same seed → same scatter (numpy and JAX engines)
   - Different seeds → different scatter (numpy and JAX engines)
7. Add tests in `test_entry.py`:
   - `--seed 42` sets `args.seed == 42`
   - Default seed is None
8. Update `Args` stub in `test_entry.py` to include `seed = None`.

**Decisions**
- Use `np.random.default_rng(seed)` (not the legacy `np.random.seed`) for numpy to avoid mutating global state.
- JAX already used a key; we simply parameterize the initial key seed.
- MLX uses `mx.random.seed()` (global state, matching its API).
- When no seed is provided, behaviour is unchanged (unseeded randomness for numpy/mlx, key(0) for JAX is preserved as the default).
