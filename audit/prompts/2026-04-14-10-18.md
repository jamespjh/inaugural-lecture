## Key Decisions and Reasoning

1. **`benchmark_range` helper** – added to `benchmark.py` so notebook code is
   clean and mirrors the interface used in the `apple.ipynb` reference
   (`benchmark_range(fn_at_size, sizes, engine=engine)`).

2. **What to benchmark** – benchmarked the gravity *law evaluation only*
   (`law.law(system)`) rather than a full `solve` call. This isolates the
   algorithmic work and shows O(n²) scaling more clearly.

3. **Engines** – `python` and `numba` are excluded (matching `ENGINES_SKIP`)
   because they are slow or partially incompatible; only `numpy` and `jax-cpu`
   were available in the sandbox environment.

4. **Committed figure** – `benchmark_engines.png` is committed as a static
   asset so the slideshow renders without a live benchmark run in CI.

5. **`image-credit` shortcode** – used instead of `video-credit` because
   the generated figure is a static PNG image.

6. **Styling** – followed the apple.ipynb reference: per-engine colours drawn
   from a consistent palette, `loglog` axes, light grid, clean labels.
