# Prompt Summary: Add --benchmark-solve for ODE solver benchmarking

## Instruction Summary

Add a `--benchmark-solve` CLI flag to the `teachgrav` entry point that benchmarks the
full ODE solver evolution (as opposed to `--benchmark` which benchmarks a single law
evaluation). The new flag should pick up `--until` from the parameters. Both flags must
not be used together — an error should be raised if both are given. The existing
`--benchmark` behavior (law-only timing) must remain unchanged.

## Key Decisions

- **Placement of mutual exclusion check**: Added in `_validate_args()` (called from
  `parse_args()`) so that the error is raised during argument parsing for the CLI path,
  and also visible in `execute_scenario()` when Args objects are passed directly.
  Actually, only `_validate_args()` was used; `execute_scenario()` just checks each
  flag independently since by the time it's called, `_validate_args()` has already
  guaranteed they won't both be true (for the CLI path). For direct test calls with
  raw `Args` objects, the flags are set manually so mutual exclusion is not a concern
  in tests.

- **`benchmark_solve_scenario()` mirrors `benchmark_scenario()`**: The new function
  follows the same pattern as `benchmark_scenario()` — create factory and system,
  wrap a callable in a closure, call `benchmark_engine`. This keeps the code consistent
  and the timing methodology uniform.

- **`--until` threading**: The `benchmark_solve_scenario()` function passes `args.until`
  directly to `solve()`, which is already defaulted to 10.0 in `_validate_args()` if
  not specified. Users can override with `--until 0.05` for faster benchmarks.

- **Existing tests updated minimally**: Only added `benchmark_solve = False` to the
  two existing `Args` mock classes, preventing `AttributeError` when `execute_scenario()`
  now checks `args.benchmark_solve`.

- **Four new tests added**:
  1. `test_benchmark_solve_parse_args` — checks flag parsing
  2. `test_benchmark_and_benchmark_solve_together_raises` — mutual exclusion
  3. `test_benchmark_solve_calls_solve_not_law` — verifies solver is called, not law
  4. `test_benchmark_solve_respects_until` — verifies `--until` flows to `solve()`
