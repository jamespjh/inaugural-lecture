# Prompts: Solar-System Scenario

Date: 2026-04-20 21:23

## Prompt Summary

The user asked the agent to implement a new `solar_system` scenario to close
a GitHub issue. The scenario should create a sun, N planets (each at increasing
radii spaced by ratio k), and optional moons for each planet (at radii h*k^j
from the planet). All bodies are mobile. Masses are 1 (moons), M (planets),
M^2 (sun). Initial speeds come from circular-orbit mechanics (v = sqrt(G*M_c/r),
G=1). Parameters: moons_per_planet (default [0,1,4,1]), M (default 1000),
k (default 1.2), h (default 0.1).

## Key Decisions

- **Naming convention**: Used the existing importlib-based pattern:
  name `"solar_system"` maps to class `SolarSystemScenario` in module
  `teachgrav.scenarios.solar_system`. This required zero changes to the factory.

- **Placement of bodies**: All planets placed along the positive x-axis at
  their respective radii (k^i). Moons placed further along x-axis at
  planet_position + h*k^j. Velocities are perpendicular (y-direction).
  This is a conventional initial condition; the dynamics will evolve naturally.

- **Moon absolute velocity**: The moon's velocity is the planet's velocity plus
  the moon's orbital velocity around the planet (both in the y-direction when
  offset is in x-direction). This ensures initial circular orbits.

- **No center-of-mass adjustment**: The issue did not request zero-momentum
  centering (unlike ScatterScenario). The sun starts at rest at the origin;
  for large M it barely moves.

- **`math.sqrt` over engine.sqrt**: Using Python's `math.sqrt` on scalar
  floats is consistent with how other scenarios compute scalar values before
  wrapping in `engine.array()`.

## Reasoning

- Checked existing scenario modules (moon, sun, scatter, single) to understand
  the pattern. All follow the same Scenario base class and `create()` method.
- Verified G=1 is the convention by inspecting the existing sun and moon
  scenarios (both use `v = 1.0` for circular orbit at radius 1.0 with mass 1.0).
- Added comprehensive tests covering body count, mass values, radii, and
  orbital velocity values to numerically validate the physics.
