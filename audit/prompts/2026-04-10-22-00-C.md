# Prompt Summary: Implement the Boids Law

## User instruction

Implement the Boids law in the teachgrav repository to close GitHub issue
"Implement the Boids law". The task was to:
- Take the numpy boids code from bad-boids/better_boids/boids.py.
- Create a law file.
- Set up an appropriate scenario to visualise.
- Put the plot into the boids slide.

## Key decisions and reasoning

### Law implementation
The original bad-boids/better_boids Boids code is object-oriented and
discrete-time. It was rewritten as a vectorised continuous-ODE law following
the existing `flat_law` / `Model` interface pattern (same as `constant_law.py`
and `pl.py`). The three rules become terms in the velocity derivative:

- **Cohesion**: `sum_j (pos_j - pos_i) * flock_attraction` over all j.
- **Separation**: `-sum_j (pos_j - pos_i)` where `|pos_j - pos_i| < avoidance_radius`.
- **Alignment**: `sum_j (vel_j - vel_i) * speed_matching_strength` where
  `|pos_j - pos_i| < formation_flying_radius`.

Default parameters match the original bad-boids implementation so that running
with `dt=1` (Euler) reproduces equivalent behaviour.

### Scenario design
The `init_boids` scenario uses the same random-initialisation ranges as the
original `initialise_random` in bad-boids (`x ∈ [−450, 50]`, `y ∈ [300, 600]`,
etc.) so that the standard parameter values produce sensible flocking without
re-tuning. All boids have equal mass (1.0) since masses are not used by the
boids rules.

### CLI extension
`--dt` and `--until` were added to the CLI because the boids scenario requires
`dt=1` (not the default 0.01) to match the original discrete-time semantics,
and because these parameters are generally useful for other scenarios too.
The existing `solve()` function already accepted these as keyword arguments;
the change wires them through from parsed CLI args.

### Slideshow
The slide 1.1.7 placeholder text was replaced with:
- The three boids rules listed explicitly.
- An HTML5 `<video>` tag inside a Pandoc raw fenced block (following the
  project convention for embedding video in `.qmd` files) pointing to
  `assets/boids_euler.mp4`.

### Testing
Ten tests covering: output shape, position-derivative semantics, immobile mask,
and all three rules verified in isolation with controlled two-boid setups.
