## Prompt Summary: RNG Seed Parameter Feature

**Date:** 2026-04-09

**Issue:** Make it so the RNG seed can be passed as a parameter (#mvp-handle-rng-seed-parameter)

**Prompt summary:** The user asked to implement the ability to pass an RNG seed as a parameter to the simulation. Different engines handle RNG seeds differently, so each must be handled carefully.

### Context and Exploration

The codebase has three array engine backends (`ArrayAbstraction`):
- **numpy**: used global `np.random.uniform` — no seed support
- **JAX**: already used a key-based PRNG (`jrandom.key(0)`) — hardcoded seed 0
- **MLX**: used `mx.random.uniform` with no seeding — no seed support

The `ScenarioFactory` class wraps `ArrayAbstraction` and uses `random_array` for the `scatter` scenario (positions, velocities, masses).

The CLI (`entry.py`) creates a `ScenarioFactory` without any seed parameter.

### Key Decisions

1. **numpy**: Switched from `np.random.uniform` (global state) to `np.random.default_rng(seed)` stored as `self.rng`. This is the modern numpy approach and avoids mutating global random state, making tests more isolated.

2. **JAX**: Simply parameterized the existing `jrandom.key(0)` to use the provided seed: `jrandom.key(seed if seed is not None else 0)`. This preserves backward compatibility (default seed 0 matches old behavior).

3. **MLX**: Added `mx.random.seed(seed)` call when a seed is provided. MLX uses global state like the old numpy API.

4. **Default behavior**: When `seed=None`, numpy uses an unseeded RNG (random), JAX uses key(0) (matching previous hardcoded behavior), and MLX is not seeded (random).

### Files Changed

- `demo/src/teachgrav/array_abstraction.py`: Added `seed` parameter, switched numpy to `default_rng`, JAX key parameterized, MLX seeding added.
- `demo/src/teachgrav/scenarios.py`: Added `seed=None` parameter to `ScenarioFactory.__init__`, passed to `ArrayAbstraction`.
- `demo/src/teachgrav/entry.py`: Added `--seed` CLI argument (int, default None), passed to `ScenarioFactory`.
- `demo/tests/teachgrav/test_scenarios.py`: Added 4 new tests for same/different seed behavior with numpy and JAX.
- `demo/tests/teachgrav/test_entry.py`: Added 2 tests for seed CLI parsing, updated `Args` stub to include `seed = None`.
